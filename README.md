# Luna Finn — website

The published files for [lunafinncreates.com](https://www.lunafinncreates.com): plain static
HTML/CSS/JS, served by GitHub Pages from this repository (`main` branch, root).

These files are **generated**. The source (`build_site.py`, original photos, and project notes)
lives on the owner's computer, not in this repository. Changes are made there and rebuilt, so
hand edits to the `.html` files here would be overwritten on the next build.

## Contents
```
index.html  about.html  press-kit.html  resume.html  workshop-menu.html  video.html
gallery.html  aerial.html  makeup.html  productions.html  movement-quest.html  contact.html
404.html

main.js                sticky header, mobile menu, scroll fade-ins, gallery lightbox
favicon.svg  robots.txt  sitemap.xml  .nojekyll  (CNAME once live)
assets/
  logos/               logo_wordmark.png (header/hero), logos_01.png (original)
  img/<category>/full/   web-sized images (max 1800px) for the lightbox
  img/<category>/thumb/  smaller images (max 760px) for grids
  img/workshop/        workshop menu graphics (PNG)
  downloads/           press-photo pack (metadata stripped)
```

## Fonts
Cormorant Garamond (headings) and Montserrat (body), loaded from Google Fonts.
